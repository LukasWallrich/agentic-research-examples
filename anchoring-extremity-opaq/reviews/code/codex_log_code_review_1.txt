    14	- RQ1: Within the same item, does the proportional influence of the anchor on estimates (the local elasticity of the estimate with respect to the anchor, on the log scale) rise, stay constant, or fall as the anchor moves further from the true value?
    15	- RQ2: Across item-study cells with a classic high/low anchor pair, does the log-scale anchoring index rise, stay constant, or fall with anchor extremity?

    19	
    20	Notation. For each estimate, y = ln(estimate / true value) and x = ln(anchor / true value). Within item-study cells we fit y = a_cell + b·x + g·x|x| (plus random effects; Q19). b is the average elasticity at the true value; g is the curvature: g > 0 means the anchor's proportional pull grows with extremity, g < 0 means it shrinks. rho = g / b is the curvature relative to the average elasticity.
    21	
    22	Models (full specification in `R/models.R`; all operate on the log scale):
    23	- **M0 No anchoring.** Estimates ignore the anchor.
    24	- **M1 Anchor-and-adjust with a fixed number of adjustments** (Lieder et al., 2018a, with the number of adjustments held constant): a Metropolis-Hastings chain starts at the anchor and takes t steps towards the belief distribution.
    25	- **M1R Resource-rational anchor-and-adjust** (Lieder et al., 2018a, Eq. 2): as M1, but the number of adjustments minimises expected absolute error plus a time cost per adjustment, so it depends on how far the anchor lies from the belief.
    26	- **M2 Constant-weight integration** (in the spirit of the anchor integration model, Turner & Schley, 2016, with a constant weight): the estimate is a fixed weighted average of anchor and belief.
    27	- **M3 Adjust to the plausible boundary** (Epley & Gilovich, 2006): anchors inside the plausible range are accepted; from anchors outside it people adjust to the nearest edge of the range.
    28	- **M4 Plausibility-discounted integration** (selective accessibility with a plausibility gate; Strack & Mussweiler, 1997; Wegener et al., 2001): the anchor's weight falls smoothly as the anchor becomes implausible.

   128	- H1a/H1b use the same rules within each stratum; if they disagree in sign (both CIs excluding 0 in opposite directions), we report that anchor type moderates the shape and do not pool the conclusion.
   129	- Gate G2 (anchoring present across cells): H2 is interpreted only if the lower bound of the 95% CI for the mean log anchoring index (intercept-only multilevel model) is above 0.
   130	- H2 decision: the same ordered rule applied to d, with its own equivalence bounds (Q20).
   131	- H3: a model is contradicted by a statistic when the observed point estimate lies outside that model's 95% predictive interval. Shape criterion (decides survival): a model survives if the observed g or rho, and the observed d, lie inside its intervals; M0 is also contradicted whenever gate G1 passes.     19	# Metropolis-Hastings adjustment from the anchor towards the belief N(mu, sigma^2)
    20	# (Lieder et al., 2018a). steps can differ by row; proposals have SD s * sigma.
    21	adjust <- function(x, mu, sigma, s, steps) {
    22	  z <- x
    23	  for (i in seq_len(max(steps))) {
    24	    active <- steps >= i
    25	    prop <- z + rnorm(length(z), 0, s * sigma)
    26	    log_ratio <- ((z - mu)^2 - (prop - mu)^2) / (2 * sigma^2)
    27	    z <- ifelse(active & log(runif(length(z))) < log_ratio, prop, z)
    28	  }
    29	  z
    30	}

    66	respond <- function(model, x, mu, sigma, par) {
    67	  d <- x - mu
    68	  switch(model,
    69	    M0 = mu,
    70	    M2 = mu + par$w * d,
    71	    M3 = ifelse(abs(d) < par$k * sigma, x, mu + sign(d) * par$k * sigma),
    72	    M4 = mu + par$w * d * exp(-d^2 / (2 * (par$c * sigma)^2)),
